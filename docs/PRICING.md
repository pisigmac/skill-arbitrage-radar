# Pricing

## Tiers

### Free ($0)
- Public arbitrage opportunity listings
- Basic demand/supply stats
- Browse portfolio projects

### Pro ($29/month)
- Personalized recommendations
- Full portfolio generator
- Outreach templates (all channels)
- Execution kanban with defaults
- Income tracker with analytics
- Priority data freshness

### Enterprise ($99/month)
- Everything in Pro
- API access (10K requests/month)
- Team seats (up to 5)
- Custom scraper configuration
- Dedicated support
- White-label option

## Billing Logic
- Stripe subscription with monthly/annual
- Annual: 2 months free ($290/year for Pro)
- Usage-based overages for API calls
- Prorated upgrades/downgrades
